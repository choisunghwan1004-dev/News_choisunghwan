# AI 데이터 저널리즘 뉴스 스튜디오 V2.0.1 — 기능별 로직 점검

## 발견한 원인과 수정
- **크롤링 → 빅데이터 전환:** 기존 `labs.js`의 `crawlToBig` 핸들러가 수집 결과로 JSONL 파일을 만들고 곧바로 `data-page="bigdata"`를 클릭한 다음 `runBig()`을 실행했다. 크롤링 자체의 `crawlRun`과 `crawlDemo`는 메뉴를 전환하지 않았다.
- **수정:** `crawlToBig`은 분석용 JSONL을 **준비만** 한다. 새 `crawlOpenBig`을 **별도로 클릭해야** 빅데이터 화면으로 이동하고 분석한다. 상태 문구 및 버튼 비활성화 추가.
- **오래된 결과 오용:** 크롤링 실패 후 기존 `cData`가 살아 있어 전달될 수 있었다. 새 시도마다 이전 결과와 전달 준비를 초기화하고, 중복 요청 시 최신 요청만 결과를 적용한다.
- **빈 JSONL:** API가 0행/0열을 정상 결과로 내보내던 경로를 400 오류로 변경해 빅데이터 UI에서의 열 접근 오류 예방.
- **속보 수치 공란:** `Number('') === 0` 때문에 빈 입력을 0으로 받아들이던 검증을 수정.

## 자동 테스트
- `cd src && go test ./...`
- `node --test tests/engine.test.js`
- `python tests/ui_navigation_regression.py` (Playwright와 Chromium 필요)
- API 스모크: 16개 원본 노트북 발견, `/api/health` 버전 2.0.1, CSV·뉴스·크롤링·JSONL·학습·선택형 음성 설치 검사

## 유지·제한
- 기존 편집 화면의 UI 레이아웃, 템플릿 27개, 원고·자막 생성, 원본 노트북을 변경하지 않았다.
- 크롤링은 현재 **공개된 정적 HTML** 본문 일부 추출이며, JS 렌더링·로그인 사이트는 지원하지 않는다.
- 실제 음성 인식, GPU 기반 LoRA, 실제 외부 크롤링 및 Windows 실기기 동작은 이번 환경에서 검증하지 못했다.
- 샘플은 모두 교육용 가상 자료이므로 보도 전 원출처와 권리를 별도로 확인해야 한다.
