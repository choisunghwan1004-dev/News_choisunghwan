# 업로드 소스 분석 및 추가 구현 내역

## 분석한 원본
- 제공 파일: `ai-datajournalism-labs-main.zip`
- 루트 README: 데이터 시각화 → 크롤링 → 파인튜닝 → n8n 자동화 실습
- 총 Jupyter 노트북 **16개** 및 원본 Python 코드, HTML, 이미지, 패키지 목록
- 수업 환경: Python 3.12 권장, pandas/Matplotlib/seaborn, Jupyter, Selenium 등
- 선택 실습: PyTorch CUDA, Unsloth, Whisper+ffmpeg, Ollama, 네트워크 또는 별도 CSV 데이터 필요
- 기존 저장소에는 통합 Windows GUI 실행 프로그램이 제공되지 않았음

## 구현 방식
- 뉴스 스튜디오는 **Go 표준 라이브러리 기반 로컬 HTTP 앱**으로 제작함
- Windows amd64 `.exe`에서 기본 브라우저를 열어 사용
- 뉴스 원고는 **규칙 기반 템플릿 엔진**이 생성함; 외부 LLM 호출 없음
- 3개 주제 × 3개 길이 × 3개 전달 방식 = **27개 조합**
- 파일 내려받기: TXT, SRT, JSON, 조건별 27개 합본
- 그래프 비교, 한국어 TTS(브라우저 음성 지원 시), 수치 편집
- 사용자가 기록하는 검증 체크리스트와 정정 이력
- **가상 데이터의 출고 보류 상태는 확인 체크 후에도 유지**
- `original/`에 제공 ZIP과 압축 해제 원본 전체를 보관, 수정하지 않음

## 제한과 검증 범위
- 실제 기사 사실관계, 원출처 진위, 사용권을 **자동 검증하지 않음**
- AI 얼굴/목소리 합성 및 실제 영상/MP4 렌더링은 미구현
- Jupyter 실습은 파일 원본 보존+별도 설치 안내; GPU/외부 자료 때문에 전부 실행 검증하지 않음
- 뉴스 스튜디오 엔진의 계산/타임라인/출력은 자동 단위 테스트
- HTTP UI 정적 파일 및 API는 Linux 환경에서 실행 테스트
- Windows amd64로 교차 컴파일했으며 실제 Windows PC에서 실행 검증은 별도 필요
