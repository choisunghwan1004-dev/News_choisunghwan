# News_choisunghwan — AI 데이터 저널리즘 뉴스 스튜디오 V2.0.1

Windows 10/11 (64비트)용 데이터 저널리즘 교육 및 뉴스 제작 프로그램입니다.

## 실행 방법

1. 전체 프로젝트를 다운로드하고 압축을 해제합니다.
2. `01_뉴스스튜디오_실행.bat` 또는 `DataJournalism_NewsStudio.exe`를 실행합니다.
3. 로컬 브라우저에서 통계·시각화, 뉴스 빅데이터, 웹 크롤링, AI 모델 학습, 뉴스 자동화, 뉴스 원고 제작을 사용합니다.

## 핵심 기능

| 메뉴 | 기능 |
| --- | --- |
| 통계·시각화 | CSV·JSONL 분석, 기술통계, 막대·선·원형 SVG 차트 |
| 뉴스 빅데이터 | 뉴스 집계, 분야·지역·제목 키워드 통계 |
| 웹 크롤링 | 허용된 공개 HTML 추출, JSONL 저장 및 2단계 분석 연결 |
| AI 모델 학습 | 경량 뉴스 분류 모델 훈련·평가·튜닝 비교 |
| 뉴스 자동화 | 값 변화 감시 시뮬레이션, 브라우저 음성 인식, 로컬 전사 옵션 |
| 뉴스 제작실 | 가상 통계 기반 뉴스 원고·자막, 27개 샘플, 사실 확인 |

## 소스 구조

- `src/` : Go 로컬 API 서버 및 HTML/CSS/JavaScript 화면
- `demo/`, `samples/` : 교육용 가상 데이터와 예시
- `tests/` : 핵심 로직 및 화면 전환 회귀 테스트
- `original/` : 업로드받은 교육용 Jupyter 노트북의 보존본
- `backup_v1/` : 초기 뉴스 스튜디오 백업
- `docs/` : 기능 설명, 검증 결과, 저널리즘 원칙

## 개발·테스트

- Go 1.23 이상: `cd src` → `go test ./...`
- Node.js: `node --test tests/engine.test.js`
- 일부 UI 테스트에는 Python 및 브라우저 자동화 도구가 필요합니다.

## 주요 주의사항

- 샘플은 **가상 데이터**이며 실제 기사나 뉴스로 배포하기 전에 원 출처 검증이 필요합니다.
- 크롤링은 대상 사이트 이용약관·robots 정책과 관련 법령을 준수해야 합니다.
- EXE는 소스에서 빌드된 Windows 프로그램입니다. Windows 실기기 최종 검증은 별도입니다.
- **경량 텍스트 분류는 GPU/LLM 파인튜닝이 아닙니다.** 원본 GPU 실습에는 추가 환경이 필요합니다.
- `original/`에는 별도 저작권이 있을 수 있는 학습자료가 있으므로, 외부 공개 전에 재배포 권한을 확인하세요. 우선 **Private 저장소**를 권장합니다.
