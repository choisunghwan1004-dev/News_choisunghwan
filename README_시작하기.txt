데이터 저널리즘 뉴스 스튜디오 V2.0.1 / Windows 10·11 x64
======================================================

※ 업로드한 ai-datajournalism-labs-main.zip 원본을 변경 없이 보관합니다.
※ V1.0 뉴스 클립 제작실, 27개 조건별 원고, 사실 확인/정정 기능도 그대로 유지합니다.

[1] 바로 시작
압축을 해제한 뒤 01_뉴스스튜디오_실행.bat 또는
DataJournalism_NewsStudio.exe 를 더블클릭합니다.
기본 브라우저에서 로컬 프로그램 화면이 열립니다. Python 설치는 필수가 아닙니다.

[2] 새로 추가한 다섯 실습 메뉴
① 통계·시각화
   CSV/JSONL 파일 → 평균, 중앙값, 최솟값, 최댓값, 결측값, 고유값 분석
   → 범주별 막대/꺾은선/원형 그래프 → SVG/JSON 내보내기.
   최대 UTF-8 20MB / 20만 행 / 100개 열. CP949 파일은 UTF-8로 변환해야 합니다.
② 뉴스 빅데이터
   뉴스 CSV/JSONL → 분야/지역 집계, 기사 제목 키워드 빈도, 수치 열 통계.
   내장 가상뉴스 180개 샘플 또는 demo/뉴스_가상자료.csv (120행) 사용.
③ 웹 크롤링
   공개 HTML 주소 1~3페이지 → 제목/본문 일부 추출 → JSONL 다운로드.
   '오프라인 HTML 샘플'로 외부 접속 없이 실습 가능합니다.
   2.0.1에서는 수집 후에도 크롤링 화면을 유지합니다.
   '빅데이터 분석용 데이터 준비' → '빅데이터 화면에서 분석 실행'
   두 버튼을 순서대로 눌러야 화면이 이동하고 분석이 시작됩니다.
   새로운 수집이 실패하면 이전 크롤링 결과/전달 준비를 무효화합니다.
   외부 수집은 인터넷 연결 및 대상 사이트 정책이 필요합니다.
   기본 robots.txt Disallow 확인 및 내부 IP 차단. 동적 JS 렌더링/로그인 미지원.
   크롤링 결과의 JSONL은 명시적 2단계 버튼으로 뉴스 빅데이터 메뉴에 전달할 수 있습니다.
④ AI 모델 학습
   label,text 형식 CSV → 다항 나이브베이즈 분류기 실제 학습.
   데이터 훈련/검증/시험 분할 → 기준/튜닝 모델 평가 → 미사용 시험셋 비교.
   이것은 경량 텍스트 분류 ML이며 LLM LoRA/Unsloth 파인튜닝이 아닙니다.
   실제 Qwen2.5-3B GPU 파인튜닝은 02 환경설치 → 03 Jupyter 실행 뒤
   원본 '4_파인튜닝/2_train_unsloth_gpu.ipynb'에서 진행합니다.
   GPU/CUDA/Unsloth/모델 다운로드 등은 별도 설치 및 준비가 필요합니다.
⑤ 뉴스 자동화
   변경 전/후 값과 경보 기준으로 속보 시뮬레이션.
   브라우저 마이크 받아쓰기(브라우저 지원/권한 및 인터넷이 필요할 수 있음).
   녹음 파일 전사는 04_음성인식_설치.bat를 실행한 경우에만 사용 가능.
   로컬 faster-whisper tiny CPU 모델은 최초 실행 시 다운로드될 수 있습니다.
   누구에게도 실제 속보를 전송하거나 자동 발행하지 않습니다.

[3] 기존 기능 (모두 유지)
✦ 뉴스 클립 제작: 세 주제, 30/60/90초, 세 전달 방식, 27종 샘플.
✦ TXT/SRT/JSON 원고 저장과 브라우저 한국어 TTS 미리 듣기.
✦ 기사 원출처/권리/승인 기록과 '바로잡습니다' 정정 이력.
✦ 업로드 원본 Jupyter 노트북 16개 다운로드/원본 폴더 보기.

[4] 선택 설치
02_노트북_환경설치.bat : Python/Jupyter 실습 (인터넷·Python 필요)
03_노트북_열기.bat : 노트북 실행 (02 설치 후)
04_음성인식_설치.bat : 녹음 파일 로컬 인식 (인터넷·Python 필요)
설치/실행 오류가 있으면 DataJournalism_NewsStudio_Console.exe 를 열어
출력되는 메시지를 확인하세요. 또는 VS Code에서 src/ 코드를 검토할 수 있습니다.

[5] 샘플 사용
 - 통계·시각화 → '교통량 샘플 사용' → 연도별 차트 확인
 - 뉴스 빅데이터 → '뉴스 샘플 사용' → 분야별 기사 분포 및 키워드 확인
 - 웹 크롤링 → '오프라인 HTML 샘플' → JSONL 내려받기
 - AI 모델 학습 → '가상 뉴스 샘플 사용' → '학습·튜닝·비교 실행'
 - 뉴스 자동화 → 현재값 57, 이전값 42, 기준 10 → 경보. 현재값 46 → 기준 미달.
 - demo/ 폴더에서 UTF-8(일부 BOM) CSV 4종과 HTML을 제공합니다.
 - V2_화면_미리보기.html은 EXE 실행 전 디자인 확인용이며
   다섯 새 기능의 실제 API는 EXE 실행 환경에서만 작동합니다.

[6] 주의
 - 가상 데이터는 현실 통계·사건이 아닙니다. 실제 기사 배포 금지.
 - 숫자·인용 원출처, 저작권, 음성·사진 권리 확인은 반드시 사람이 해야 합니다.
 - 승인 체크를 해도 실습 데이터는 기사로 출고할 수 없습니다.
 - 자동 분류 모델 성능은 예제 데이터에 한정되며 일반화되지 않습니다.
 - Windows EXE는 교차 빌드 후 바이너리 형식을 확인했으나,
   실제 Windows PC에서의 실행/마이크/GPU/인터넷 수집은 미검증입니다.
 - 디지털 서명되지 않은 EXE이므로 PC에서 경고가 표시될 수 있습니다.
 - 서버는 기본적으로 127.0.0.1의 임시 포트에 바인딩합니다.
 - 원본 소스 백업: original/ai-datajournalism-labs-main.zip
 - 구버전 롤백: backup_v1/DataJournalism_NewsStudio_Windows_v1.0.zip

[8] V2.0.1 수정 / 문제 재현 검사
 - 원인: src/web/labs.js에서 crawlToBig 클릭 시 데이터 준비, 메뉴 전환, 뉴스 분석을 한 번에 실행.
 - 수정: '준비' 버튼은 크롤링 화면을 떠나지 않음. '분석 실행'을 별도로 눌렀을 때만 이동.
 - 실패/재수집 시 옛 크롤링 자료 및 전송 준비 폐기. 중복 요청은 나중 요청만 적용.
 - JSONL이 빈 경우 서버에서 분명한 400 오류 안내.
 - 속보 경보 수치가 빈칸일 경우 0으로 간주하지 않고 입력 오류 처리.
 - 원본 16개 노트북과 기존 뉴스 제작 기능, CSS·상태를 보존.
 - 검증: Go 테스트, Node 테스트, 실제 Go API 통합 테스트,
   Chromium DOM UI 회귀 테스트 (tests/ui_navigation_regression.py).
 - Windows 실기기/외부 사이트/마이크 실사용은 별도 검증 필요.
